## Features

### SITES
- View all your sites at a glance
- Site status and deploy previews
- Quick access to live URLs

### DEPLOYS
- Trigger new deploys
- View deploy logs in real-time
- Rollback to previous deploys
- Lock/unlock production deploys

### DOMAINS
- Manage custom domains
- DNS configuration status
- SSL certificate details

### BUILD SETTINGS
- Edit build commands
- Manage environment variables
- Configure build hooks

### ANALYTICS
- Bandwidth usage
- Build minutes tracking
- Function invocations

## Environment
- macOS 14+ (Sonoma)
- Node v24
- Npm v10.9 (please don't commit a `yarn.lock` file, we are using `npm` both for development and building)
- Xcode 26
